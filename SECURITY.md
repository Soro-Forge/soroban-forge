# Security Policy

Soroban Forge performs static checks on source text. Findings are not a security
audit, and a clean result is not proof that a contract is safe.

Please report suspected security vulnerabilities privately using GitHub's
private vulnerability reporting on the repository Security tab, if available.
Include a minimal reproduction and avoid publishing exploit details while a fix
is being coordinated. If private reporting is unavailable, open an issue asking
for a private contact without including sensitive details.
